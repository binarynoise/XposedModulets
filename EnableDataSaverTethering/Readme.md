# EnableDataSaverTethering

Enable tething while data saver is active.

Android automatically disables all tethering options while the data saver is activated.
Since tethering is a manual user decision, this is not very useful.
It is especially annoying when using tethering while connected to WiFi.
This module makes the tethering settings ignore the data saver, 
allowing them to be toggled on and off regardless.
